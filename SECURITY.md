# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `cf-doh`, please report it privately to the maintainer via GitHub Security Advisories or by contacting the maintainer directly.

Please do not open public issues for security vulnerabilities.
